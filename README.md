# Safelight Border — discontinued

**Border is discontinued.** Solid borders are now part of **Framing / Border**:

```
OPGERUIMD97/safelight-mat-frame
```

Please **deactivate and uninstall** this extension in Safelight → **View → Extensions**, then open the new module and use **Border** mode (or **Import Border** for your saved templates).

Templates stay in browser storage under `safelight-border-*` for migration.

## Changelog

### 1.1.0 — discontinued
- No export processor / Develop overlay
- Panel notice: deactivate and uninstall; switch to Framing / Border

### 1.0.0 — Initial release
Solid-color border, per-side px widths, templates, Develop overlay, Export Apply.
